# 麦麦省钱军师（mcd-saver-guru）

> 同一个麦当劳订单，券、积分、活动三条路各能省多少？这个 Skill 帮你算清楚，并直接给出最省的下单方案。

基于**麦当劳 MCP Server** 开发，把优惠券、会员积分、营销活动、门店价格四类能力串成一条省钱决策流水线，输出一份可直接照着下单的「省钱方案卡」。

## 目标用户

- **精打细算的日常消费者**：想知道「这单还能不能更便宜」，又懒得逐张比对优惠券
- **积分快过期的人**：手上有积分但不知道怎么用最划算
- **代点/团购场景的决策者**：要给一群人搭配一顿性价比最高的麦当劳
- **麦门铁杆粉丝**：想第一时间知道麦麦省新券和限时活动

## 核心能力

不做「点餐机器人」，做**决策军师**——回答「同一顿饭怎么点最便宜」。

| 能力 | 说明 |
|---|---|
| 🔖 一键薅券 | 扫描麦麦省当前可领券，按与本单的相关性筛选后一键领取 |
| 💰 资产盘点 | 卡包券 + 积分余额（含即将过期提醒）+ 未使用奖品券 |
| 📅 活动扫描 | 营销活动日历，抓限时套餐、麦金卡/学生卡、买一送一 |
| 🧮 三条省钱线试算 | 券线 / 积分线 / 活动线**各跑一次真实价格接口**，横向比实付 |
| 📊 省钱方案卡 | 输出推荐 + 备选方案的实付、省额、省率与理由 |

## 安装方法

### 前置条件

需要申请麦当劳中国 MCP Token（见 [麦当劳 MCP Server 使用指南](https://github.com/M-China/mcd-mcp-server)）。

### 1. 配置 MCP 连接器

在 WorkBuddy 左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】中，粘贴 `mcp-config.example.json` 的内容，并把 `${MCD_MCP_TOKEN}` 替换为你的实际 Token：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

保存后回到【自定义连接器】启用 `mcd-mcp`。

### 2. 安装 Skill

把本仓库的 `SKILL.md`、`references/`、`scripts/`、`assets/` 复制到 WorkBuddy 的技能目录：

```
~/.workbuddy/skills/mcd-saver-guru/
├── SKILL.md
├── references/
│   ├── mcp-tools.md
│   └── saving-strategy.md
├── scripts/
│   └── savings_rank.py
└── assets/
    └── savings-report.html
```

重启会话后，技能会自动按描述匹配触发。

> 也可以直接使用打包好的 `mcd-saver-guru.zip` 分发。

## 使用示例

### 示例 1：日常省钱

> **用户**：今天中午想吃麦当劳，到店自取，两个人，预算 50，怎么点最省？

```
🍟 麦麦省钱方案卡 ｜ 到店自取 · 麦当劳（XX 店）

🥇 推荐：券线 + 9.9 早餐活动叠加方案
　 商品：龙焰鸡腿堡三件套 ×2
　 原价：¥53.80
　 优惠：门店可用 9.9 元早餐券 + 会员券 -¥XX.XX
　 实付：¥XX.XX　省 ¥XX.XX（XX%）
　 理由：命中本周限时活动，且用掉 3 天后过期的券
...
```

### 示例 2：积分处理

> **用户**：我有多少积分？积分能换什么？快过期了吗？

Skill 会调用账户接口，明确回答可用积分与**即将过期积分**，并从积分商城按「积分/元」兑换率排序推荐最划算的兑换项——实测最低可达 50 积分换 6.9 元商品。

### 示例 3：领券

> **用户**：帮我领券。

用户确认后一键领取全部可领券。

## 设计要点

- **价格只信价格接口**：任何金额必须经 `calculate-price` 试算（返回单位为分，展示时 ÷100），禁止估算。
- **区分「卡包券」与「门店可用券」**：前者只代表拥有，后者才代表这单能用。
- **过期资源优先**：优先安排即将过期的积分与奖品券。
- **不硬凑优惠**：没有优惠空间时如实告知，而不是拼凑无用的券。
